SpecAnalytiXBase
=================

SpecAnalytiXBase is a desktop application for importing, processing,
and analyzing spectroscopic data (UV-Vis, CD, IR/FTIR, Raman, NIR, NMR,
and similar). It covers the full workflow from raw instrument files
through baseline correction, smoothing, and normalization, to
multivariate analysis (SVD, PCA, NMF, MCR-ALS), clustering, reference
matching, and more - with every step tracked in an undoable Operations
History.

Getting started
----------------

Once the application is running, open the Help menu and choose
"Quick Start" for a short orientation with links to the help page for
every operation and analysis tool, or "User Guide" for the full manual.

Installing / running from source
----------------------------------

See INSTALLATION.txt in the project's source folder for how to run
this application from its Python source code instead of the installed
copy, and how to build this installer yourself.
