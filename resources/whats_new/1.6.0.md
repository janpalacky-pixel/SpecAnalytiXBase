## What's new in 1.6.0

### 1.6.0 in brief
- **Data table** — the selected spectra as a spreadsheet (copy to Excel, export, formula
  columns), and a tab **Values per spectrum**: one row per spectrum with its stored values and
  values you choose (area, maximum, peak position, …), formulas, plots, and a column against
  another as a new spectrum (e.g. a melting curve). [Help](help://user_guide#data-table)
- **Peaks** — Detect Peaks and the new Peak list in one window: every peak of the selected
  spectra in a table, a plot that follows bands through a series, a band table for Excel and
  the marks on the plot. [Help](help://peak_detection)
- **Peak Fitting for a series** — fit a whole series (e.g. a temperature scan) in one window,
  each spectrum with its own peaks, with a table of the results. [Help](help://peak_fitting#series)
- **Line colours by value** — colour the spectra along a colour scale by their order, a number
  in their names or a stored value (e.g. temperature), with a colour bar.
  [Help](help://user_guide#line-colours)
- **Spectrum properties** — give each spectrum its temperature, pH, concentration, …; used by
  the colours, the Data table, the Peaks window, Melting Curve Analysis and Group Statistics.
  [Help](help://user_guide#spectrum-properties)
- **Mixture analysis (known components)** — how much of each known component is in every
  spectrum. [Help](help://user_guide#mixture-analysis)
- **Copy plot to clipboard** (Ctrl+Shift+C) — paste the plot straight into Word or PowerPoint.
  [Help](help://user_guide#plot-export)
- **Zoom the plot while a window is open** — most tool windows (Peak Fitting, Peaks, Normalization,
  Baseline, the Data table, plot settings, …) stay open beside the plot: zoom, pan and save it
  meanwhile; **Hide the window** / **Close the window** in the orange line above the plot.
  [Help](help://user_guide#beside-the-plot)
- **Easier to use** — buttons for the most used tools under the menu bar, keyboard shortcuts (Help › Keyboard
  shortcuts), icons on the buttons of all windows, one Plot Properties window.
  [Help](help://user_guide#keyboard)

### New
- **Data table** (button under the menu bar, or Analysis & Visualization › Data Analysis).
  A short line at the top of each tab says what it is for; its orange **?** says more.
  - Tab *Points*: x and one column per spectrum (sp1, sp2, … as in the Spectral Calculator).
    Select cells and press Ctrl+C to paste them into Excel; Export… saves Excel, CSV or text.
    Formula columns (e.g. `sp1 / sp2`, `log10(sp3)`, `sp1 - mean(all)`) can be added to the
    spectra list as new spectra (one step in the History, so Undo removes them).
  - Tab *Values per spectrum*: one row per spectrum with its stored values (temperature, pH, …)
    and every number written in its name (n1, n2, …). **Add value…** adds e.g. the area or the
    maximum of a band, a peak position or FWHM, a ratio of two bands; a range that reaches
    beyond the spectra is narrowed to where they have data. Formula columns (e.g. `v1 / v2`);
    plot one column against another (e.g. a band's area against the temperature), or add it
    to the spectra list with **As new spectrum** - a melting curve you can process like any
    spectrum. [Help](help://user_guide#values-per-spectrum)
  - The columns you add are there again the next time you open the Data table - also after
    a restart, and saved with a snapshot.
- **Spectral Calculator**: `x` (the x values) and functions across spectra, point by point —
  `mean`, `median`, `std`, `sum`, `min`, `max` of a few spectra or of all.
- **Peaks window** (right-click on the plot › Detect Peaks or Peak list…): one window with one
  set of settings at the top (Threshold, Prominence, Distance, S/N, Peaks) and four tabs.
  Peaks are judged locally (Threshold 0 by default), so a small clear band next to a strong
  one is found, and against the noise (**S/N**, 8 by default), so the noise of weak spectra is
  not taken for peaks. [Help](help://peak_detection)
  - **List**: every peak of all selected spectra — spectrum, number, maximum/minimum,
    position, height, prominence, FWHM. Copy to Excel, Export… A double-click on a peak shows
    it on the main plot (its spectrum highlighted, the peak circled).
  - **Refine by fitting**: every found peak is fitted with a model band plus a background:
    a position between the measured points, FWHM, height above the background, area and R²
    in extra columns. **Show on the main plot** draws each fitted peak over its spectrum.
    [Help](help://peak_detection#refine-by-fitting)
  - **Plot**: one number of the peaks against another, e.g. the position of each band against
    the temperature; colours and lines that follow each band through the series.
  - **Band table**: one row per spectrum, one column per band, with the chosen value and the
    stored values such as the temperature - ready for Excel. **Open in the Data table** puts
    the bands there as columns b1, b2, … - for formulas such as the ratio of two bands.
    [Help](help://peak_detection#band-table)
  - **Mark on the plot** (Detect Peaks): the peaks marked on the main plot; the window stays
    open and the marks follow every change of a setting. With many spectra each band's
    position is written once (**Labels**: once per band, on every peak, only the current
    spectrum, none). [Help](help://peak_detection#mark)
- **Peak Fitting for a series**: select the spectra of a series and open Peak Fitting: a list
  beside the plot shows one or several of them. Everything acts on the spectra selected in the
  list: **Auto-Detect Peaks** finds the peaks of each, **Copy peaks / Paste peaks** gives them
  the peaks of one spectrum, **Fit Peaks** fits them (in parallel) - also spectra with
  different bands together (e.g. Raman and CD). With "Spectra without peaks: start from the fit
  before them" ticked, peaks set on the first spectrum follow a band that shifts along the
  series. An **Amplitude Constraint** for all spectra or for each its own. The tab **Series
  results** shows the results of the selected spectra By peak (one peak at a time, a row per
  spectrum), By spectrum (each with its peaks) or All in one table: Copy, Export, Open in the
  Data table. Views Overlay, Waterfall, Grid; Residual and Legend can be
  hidden; the Output Options add spectra for the fitted spectra you choose.
  [Help](help://peak_fitting#series)
- **Peak Fitting converges better**: Auto-Detect Peaks gives the right starting widths and no
  longer takes the dips between bands for negative peaks (e.g. 7 peaks instead of 13, fitted in
  a fraction of the time); a clicked peak gets the width of the band under the click; the fit
  can no longer run away to huge peaks cancelling each other; Zoom/Pan and Add via Click switch
  each other off. Orange "?" buttons in the window explain each part.
  [Help](help://peak_fitting#converge)
- **Line colours** (list under the plot type, or View › Line colours…): automatic colours, own
  colours (set in Plot Properties), or **colours by value** — along a colour scale (viridis,
  coolwarm, …) by the order in the list, a number in the names or a stored value, with a
  colour bar; spectra without a value are grey. Kept in snapshots; Open in New Window and Copy
  plot use the same colours. [Help](help://user_guide#line-colours)
- **Spectrum properties** (right-click on the spectra list): a table with one row per spectrum
  and one column per property. Add property…, type or paste values from Excel, fill them from
  the names or as a series, or **from a file** (spectrum names + one column per property,
  Excel/CSV/TXT); Apply (Undo takes it back). Values read from the file, e.g. `temperature_C`
  of a JASCO scan, are shown and can be corrected. [Help](help://user_guide#spectrum-properties)
- **Melting Curve Analysis**: **X from** takes the temperatures from a stored value (e.g.
  `temperature_C`), from the names, or from the first, second, … number of the names. A
  spectrum without a temperature is left empty and named under the table - no number is
  invented for it. [Help](help://melting_curve)
- **Group Statistics**: groups **From a property…** — every value a group (pH 7, pH 7.4, …) or
  two groups split at a value. Groups made from a property or from the names are worked out
  again from the current values each time the window opens. [Help](help://group_statistics)
- **Mixture analysis (known components)** (Analysis & Visualization › Data Analysis): each
  spectrum fitted as a sum of chosen reference spectra (optionally never negative, with a
  constant or sloped background): the amount of each, the residual and R²; Copy and Export.
  [Help](help://user_guide#mixture-analysis)
- **Copy plot to clipboard** (Ctrl+Shift+C, File menu, or right-click on the plot): the plot as
  a picture at 300 dpi, the size it has on the screen. [Help](help://user_guide#plot-export)
- **Help › Keyboard shortcuts…**: every keyboard shortcut in one table.

### Easier to use
- **Zoom the plot while a window is open**: most tool windows stay open beside the plot -
  e.g. Peak Fitting, Peaks (Detect Peaks, Peak list), Data range, Normalization, Baseline
  Correction, Group Statistics, SVD analysis, the Data table, Line colours and Plot
  Properties. Meanwhile you can zoom, pan and save the plot and use the Basic plot options
  (plot type, scales, legend, cursor, …), e.g. to look closely at the marked peaks or a fit;
  the rest of the main window is greyed out until the window closes. An orange line above
  the plot says which window is open: **Hide the window** shows the whole main window
  (**Show the window** brings it back), **Close the window** closes it. Legend, Grid, Layout
  Properties and Axis properties have **Apply**: the plot changes at once, the window stays
  open.
  [Help](help://user_guide#beside-the-plot)
- **Buttons under the menu bar**, in groups: Import data (with New… / Add to current…), Open
  snapshot, Save, Help, Copy plot; *Processing* - Data range, Smoothing, Baseline,
  Normalization; *Analysis* - Peak list, Peak Fitting, SVD analysis, 2D map, Group Statistics,
  Data table. In a narrow window the buttons show only their icons, group by group, so none is
  hidden. **View › Toolbars** (or a right-click on the buttons) hides a group, sets the text
  on the buttons (Automatic, Always, Never) or goes back to the default. All entries of
  the menus Spectra processing, Analysis & Visualization and Help have icons.
  Keyboard shortcuts Ctrl+I, Ctrl+Shift+I, Ctrl+O, Ctrl+S. **Peak list…** is now also in the
  menu Analysis & Visualization › Data Analysis, the **Data table…** also in the right-click
  menu of the plot. [Help](help://user_guide#toolbars)
- **Clearer File menu**: Import data › New… / Add to current…, Open snapshot…, Save…, with icons.
- **Icons on the buttons of all windows** (Close, Apply, Save…, Export…, Copy, Help, …).
- **One Plot Properties window** (button below the spectra list): line colour, style, width and
  marker of the selected spectra in a table, with Apply and Reset to defaults.
- **Long tooltips** are broken into lines.
- **Drop-down lists show their arrow**; switched-off controls are greyed out; selected table
  rows stay clearly coloured; the open tab is white with a blue line on top.
- **NMF and MCR-ALS warn** when the spectra still sit on a large background (e.g. an
  uncorrected detector offset), which makes their components jagged — baseline-correct first.
  [Help](help://map2d#nmf-mcr)

### Fixed
- **Add spectra after going back in History**: adding a file again (e.g. after History ›
  Original state) no longer names its spectra "… (2)" when no spectrum of that name is in the
  list.
- **Open in New Window**: zoom, pan and the x/y read-out work.
